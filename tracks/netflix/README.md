# Netflix-Scale Interview Track

This track contains media-delivery and consumer-scale adapters built on the canonical shared handbook.

## Track-specific domains

- Global edge and CDN behavior.
- Playback startup and continuity.
- Manifest generation.
- Segment and byte-range delivery.
- DRM, licensing, and entitlement.
- Recommendation and personalization degradation.
- Cache behavior for media workloads.
- Regional playback evacuation.
- Large consumer traffic events.

## Adapter rule

Each question file should link to shared chapters under `core/` and add only Netflix/media-specific context, failure modes, trade-offs, and follow-ups.
