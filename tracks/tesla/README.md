# Tesla SRE Interview Track

This track contains connected-vehicle, fleet, manufacturing, charging, and safety-oriented adapters built on the canonical shared handbook.

## Track-specific domains

- Vehicle-to-cloud command architecture.
- Fleet telemetry ingestion.
- Intermittently connected edge systems.
- OTA software and firmware rollout.
- Vehicle identity and certificate lifecycle.
- Hardware-generation compatibility.
- Manufacturing and factory infrastructure.
- Charging infrastructure reliability.
- Regional control-plane failure while vehicles continue operating.
- Safety-oriented rollout, rollback, and auditability.

## Adapter rule

Each question file should link to shared chapters under `core/` and add only Tesla/connected-system context, failure modes, safety invariants, and follow-ups.
